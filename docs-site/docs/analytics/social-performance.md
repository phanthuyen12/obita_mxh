# Đo Lường Hiệu Suất Tương Tác Mạng Xã Hội

Theo dõi và đánh giá hiệu quả của toàn bộ chiến dịch truyền thông đa kênh.

---

## Các Chỉ Số Đo Lường:
- **Chỉ số tổng thể:** Lượt tiếp cận (Reach), Lượt hiển thị (Impressions), Tỷ lệ tương tác (Engagement Rate) và Lượt theo dõi mới.
- **Chỉ số bài đăng:** Likes, Comments, Shares, Clicks và Views của từng bài viết.
- **Đồng bộ dữ liệu:** Nhấp nút **Sync Data** để cập nhật số liệu mới nhất trực tiếp từ API Facebook, YouTube và TikTok.
