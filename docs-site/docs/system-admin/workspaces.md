# Quản Trị Không Gian Làm Việc (Workspaces)

Hệ thống hỗ trợ tạo không giới hạn các Workspace độc lập, giúp phân tách dữ liệu an toàn giữa các thương hiệu hoặc khách hàng khác nhau.

---

## Cơ Chế Phân Tách Dữ Liệu
Mỗi Workspace sở hữu độc lập:
- Danh sách tài khoản mạng xã hội kết nối.
- Lịch xuất bản và kho lưu trữ nội dung.
- Hộp thư Omnichat và danh sách khách hàng CRM.
- Đội ngũ thành viên và phân quyền vai trò.
