# Tích Hợp REST API & Giao Thức MCP Cho AI Agent

Cung cấp khả năng mở rộng và kết nối với các trợ lý AI thông minh bên ngoài.

---

## 1. Quản Lý REST API Keys
- Quản lý Token truy cập lập trình tại **Cài đặt Workspace > API Keys**.
- Hỗ trợ các endpoint tạo bài viết, lập lịch và truy vấn dữ liệu báo cáo.

## 2. Model Context Protocol (MCP Server)
- Cung cấp sẵn MCP Server tiêu chuẩn cho các AI Assistant như **Claude Desktop, Cursor, ChatGPT**.
- Cho phép điều khiển xuất bản và tra cứu dữ liệu hệ thống bằng câu lệnh ngôn ngữ tự nhiên.
