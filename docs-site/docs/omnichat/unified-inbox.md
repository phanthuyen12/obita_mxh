# Hộp Thư Hợp Nhất Đa Kênh (Omnichat Unified Inbox)

Tập trung toàn bộ tin nhắn từ Facebook Messenger, Zalo OA, Shopee, Lazada và Telegram vào một màn hình duy nhất.

---

## Bố Cục Màn Hình Làm Việc

```text
┌────────────────────────┬──────────────────────────────────────┬───────────────────────────────┐
│ DANH SÁCH HỘI THOẠI    │ CỬA SỔ NHẮN TIN REALTIME             │ THÔNG TIN KHÁCH HÀNG (CRM)    │
│                        │                                      │                               │
│ 🔍 Tìm kiếm khách...   │ [Avatar] Nguyễn Văn A (Facebook)     │ [Avatar] Nguyễn Văn A         │
│ [Tất cả] [Chưa đọc]    │ ┌──────────────────────────────────┐ │ 🏷️ Nhãn: [Khách VIP] [Đã cọc] │
│                        │ │ Khách: Shop còn áo size L không? │ │                               │
│ • [FB] Nguyễn Văn A    │ └──────────────────────────────────┘ │ 📞 SĐT: 0912.345.678          │
│ • [Zalo] Trần Thị B    │ ┌──────────────────────────────────┐ │ ✉️ Email: vana@gmail.com       │
│ • [Shopee] Lê Văn C    │ │ Bạn: Dạ bên em còn sẵn anh nhé!  │ │ 📍 Địa chỉ: Cầu Giấy, HN      │
│                        │ └──────────────────────────────────┘ │ 📝 Ghi chú nội bộ:            │
│                        │ [ Nhập tin nhắn...        ] [Gửi]    │ Khách muốn nhận vào buổi sáng │
└────────────────────────┴──────────────────────────────────────┴───────────────────────────────┘
```

---

## Tính Năng Chính
- Nhắn tin thời gian thực qua giao thức WebSocket (Real-time).
- Hiển thị logo nhận diện nguồn kênh trên từng cuộc trò chuyện.
- Hỗ trợ gửi tin nhắn văn bản, hình ảnh và tệp đính kèm.
