# Quản Lý Khách Hàng Tiềm Năng (Leads CRM)

Lưu trữ và quản trị thông tin khách hàng phát sinh từ các kênh tương tác tại màn hình **Leads** (`/omnichat/leads`).

---

## Dữ Liệu Khách Hàng Quản Lý:
- **Thông tin liên hệ:** Họ tên, Số điện thoại, Email, Địa chỉ giao hàng.
- **Trạng thái khách hàng:** Nhãn Tag thể hiện vị trí của khách hàng trong phễu bán hàng.
- **Nhân viên phụ trách:** Nhân sự CSKH chịu trách nhiệm chăm sóc.
- **Ghi chú nội bộ:** Lịch sử tương tác và ghi chú đặc biệt về khách hàng.
- **Xuất dữ liệu:** Hỗ trợ xuất danh sách Leads ra file Excel phục vụ tiếp thị lại (Remarketing) hoặc Telesales.
